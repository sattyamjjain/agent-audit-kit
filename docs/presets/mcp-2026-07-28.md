## What it activates

The three authorization-hardening conformance rules of the MCP 2026-07-28 final
auth profile — a one-command answer to *"is this MCP deployment ready for the
2026-07-28 authorization profile?"*:

- `AAK-OAUTH-006` — RFC 9207 `iss` authorization-response validation
- `AAK-OAUTH-007` — RFC 8707 `resource` indicators (audience-bound tokens)
- `AAK-OAUTH-008` — RFC 9728 Protected Resource Metadata discovery (no static creds)

## Usage

```bash
agent-audit-kit scan . --profile mcp-2026-07-28
# equivalent:
agent-audit-kit scan . --preset  mcp-2026-07-28
```

`AAK-OAUTH-008` evaluates configuration files (a remote MCP server config that
embeds a static credential with no Protected-Resource-Metadata discovery);
`AAK-OAUTH-006` and `AAK-OAUTH-007` evaluate OAuth flow **source code** (they are
inert against `.mcp.json` connection configs). To exercise all three, point the
scan at a client/server source tree, not only a config directory.
