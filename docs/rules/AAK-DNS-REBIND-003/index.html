    AAK-DNS-REBIND-003: State-changing routes beside an MCP endpoint, with no Host or Origin check

    Severity
    CRITICAL
    Category
    Transport Security (transport-security)
    Scanner
    agent_audit_kit/scanners/dns_rebind.py
    Auto-fixable
    No.
    SARIF name
    McpListenerRoutesDnsRebind

    What it detects

    An MCP server that serves its MCP endpoint over HTTP registers other routes on the same listener that change state (POST, PUT, PATCH or DELETE), and nothing checks the Host or Origin of a request to them or asks it for a credential. The MCP SDKs' DNS-rebinding protection (the Python SDK's transport security, the TypeScript transport's allowedHosts) checks requests to the MCP endpoint alone, so a page a user visits can rebind its own name to the listener's address and call the other routes from the browser. Binding to loopback does not close that: rebinding is how a page reaches loopback. jupyter-mcp-server before 1.0.3 (CVE-2026-77359, CVSS 4.0 9.3) checked Host and Origin on /mcp while its FastMCP custom_route routes PUT /api/connect and DELETE /api/stop checked neither, so a page replaced the runtime and document URLs, pointing the kernel client at a server of its choosing, and stopped the notebook kernel. AAK-DNS-REBIND-001 reports the MCP endpoint itself; this rule fires whether or not that endpoint is protected.

    How to fix

    Check the Host of every request the listener serves, not only those to the MCP endpoint. In Starlette or FastAPI put TrustedHostMiddleware(allowed_hosts=[...]) on the outermost app, or, for FastMCP custom_route routes, add_middleware it on the app streamable_http_app() returns; in Express build the app with the SDK's createMcpExpressApp() or app.use(hostHeaderValidation([...])). Refuse a request whose Origin is not one you serve, and require a credential on routes that reconnect, reconfigure or stop the server. jupyter-mcp-server 1.0.3 does all three in one middleware in front of its management routes.

    To confirm the finding is gone, report only this rule:

    agent-audit-kit scan . --rules AAK-DNS-REBIND-003

    Limitations

    Reads .py, .ts, .tsx, .js, .mjs and .cjs files that build an MCP transport AAK-DNS-REBIND-001 reads, protected or not, and Python files that register a FastMCP custom_route and import FastMCP or MCPServer from mcp, or import the fastmcp package; test files and paths under a test directory are skipped. A route is a FastMCP custom_route, a Starlette Route or add_route, a FastAPI add_api_route or api_route, or a Flask route or add_url_rule, whose literal methods list names POST, PUT, PATCH or DELETE (with no list, the framework's GET default is taken); a FastAPI or Flask post, put, patch or delete decorator; or an Express, Fastify or Hono post, put, patch, delete or all call on a name bound to express(), Router(), fastify(), new Hono(), polka() or createMcpExpressApp(), or named app, router, server, fastify, hono or api. A path or a methods list that is not a literal, a Starlette HTTPEndpoint class, Fastify's route({...}) and Hono's on() are not read, and neither is the MCP transport's own path (/mcp, /sse, /messages). A Host or Origin read anywhere in the file outside a comment (the header by name, Starlette's request.url.hostname, HTTP_HOST, Django's get_host(), Flask's request.host, req.hostname in TS/JS) is taken to check every route, with nothing to show the check runs on them. In Python a TrustedHostMiddleware with an allowed_hosts other than its default or ["*"] covers the routes of the app it is applied to, an app told by the name it is assigned to in the same function: one on the app streamable_http_app(), sse_app() or http_app() returns covers that app's custom_route routes only, one on any other app every route in the file. In TS/JS an X.use(...) middleware with the word host or origin in its name (cors never counts) covers the routes under its path, and so does an app from createMcpExpressApp() unless it is given 0.0.0.0 or :: without allowedHosts. A credential counts as AAK-WEBSOCKET-SERVER-001 reads one (authorization, basic_auth, api_key, apikey, bearer, or token or auth as a word) in the route's registration or its handler, wherever the handler is defined in the file, and in TS/JS also a middleware on the route, or used over its path, with the word auth, token, bearer, jwt or credential, or api and key, in its name; what the check does with it is not read. A route registered in a file other than the one that serves MCP is not read, and middleware another file applies to the app is not seen. A source file over 512 KB is not read.
